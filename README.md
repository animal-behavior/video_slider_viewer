## Установка:
1. Установите [uv](https://docs.astral.sh/uv/)

2. Установка зависимостей:
```
uv sync
```

## Запуск:
```
uv run python video_slider_viewer.py
```

## Как пользоваться:
1. Загрузите видео
2. Загрузите csv файл в следующем формате:

| frame | iliac crest x | iliac crest y | hip x | hip y | knee x | knee y | ... |
|-------|---------------|---------------|-------|-------|--------|--------|-----|
| 0     | 1669          | 727           | 1660  | 765   | 1666   | 753    | ... |
| 1     | 1678          | 746           | 1660  | 766   | 1667   | 754    | ... |

Первой идет колонка с номером кадра - **'frame'**, далее попарно координаты части тела

Столбцы с координатами в следующем порядке: **iliac crest -> hip -> knee -> ankle -> mtp -> toe** 

Это важно для корректного соединения узлов

3. Установите начальный и конечный номера кадров
4. Нажмите кнопку 'Set Frame Range'
5. Ползунком переключайте кадры (номер текущего кадра отображается в правом верхнем углу)

## Статистическая фильтрация выбросов (`filter_outliers.py`)

Отдельный CLI-скрипт для очистки координатных CSV от аномальных точек. Применяет каскад из трёх независимых детекторов на основе устойчивой к выбросам MAD-статистики:

- **Hampel-фильтр** (per-axis) — одиночные всплески.
- **Velocity z-score** (per-joint) — резкие «прыжки» по евклидовой скорости.
- **Bone-length consistency** — нарушения длин «костей» по цепочке `iliac_crest → hip → knee → ankle → mtp → toe`.

### Базовое использование:
```
uv run python filter_outliers.py "new_Intact_1.csv"
```

Создаёт рядом со входным файлом:
- `<input>_filtered.csv` — очищенные координаты.
- `<input>_outliers.csv` — отчёт: `frame, joint, axis, original_value, replacement, reason`.

В stdout печатается сводка по каждому суставу: число помеченных кадров и разбивка по причинам.

### Стратегии замены (`--replace`):
- `interpolate` (по умолчанию) — линейная интерполяция между валидными соседями.
- `zero` — выброс заменяется на `0,0` (совместимо с DLC-форматом и просмотрщиком).
- `nan` — пустая ячейка.

### Полезные флаги:
- `--mask-zeros` — трактовать пары `(0, 0)` во входе как пропуски (для уже частично отфильтрованных DLC-файлов).
- `--velocity-k 7` — поднять порог скорости (дефолт 5.0). Для быстрых дистальных суставов (ankle/mtp/toe) дефолт может срабатывать слишком часто.
- `--hampel-window 11 --hampel-k 4` — окно и порог Hampel.
- `--bone-length-k 4` — порог для проверки длин костей.
- `--skip-hampel` / `--skip-velocity` / `--skip-bone-length` — отключить отдельные детекторы.
- `--chain iliac_crest,hip,knee,ankle,mtp,toe` — переопределить анатомическую цепочку.
- `--output PATH` / `--report PATH` — задать пути выходных файлов вручную.
- `--quiet` — без сводки в stdout.

Полный список флагов: `uv run python filter_outliers.py --help`.
